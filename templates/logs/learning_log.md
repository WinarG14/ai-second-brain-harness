# Learning log

One entry per correction or reusable finding. The learning-digest skill proposes a promotion
after 2 or more occurrences.

Entry format:

    ## <short rule>   [pattern]
    - Trigger: <when the rule applies>
    - Occurrences: YYYY-MM-DD (<evidence>)
    - Suggested action: <destination file and exact change>

Tags: `[pattern]`, `[promote→skill|memory|process:<path>|recipe:<path>]`, `[done→<path>]`, `[archived→stale]`.

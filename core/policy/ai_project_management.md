# Playbook — AI Project Management

AI means Artificial Intelligence. This playbook applies when a feature uses Large Language Models (LLMs), Machine Learning (ML), Operations Research (OR), image recognition, automation, or agent systems.

## Trigger

Use when the request involves AI, LLM, agent, chatbot, SMART, Compass, model, prediction, classification, extraction, optimization, or automation.

## AI lifecycle

1. Request and review.
2. Proof of Concept (POC).
3. Pilot.
4. Productization.

## AI-able assessment

Check whether the target workflow has:

- manual work,
- repeated steps,
- clear input and output,
- high time/cost pain,
- verifiable output,
- acceptable error tolerance.

## Technology choice

- Stable if-then logic: rule-based automation.
- Structured prediction: traditional Machine Learning.
- Optimization under constraints: Operations Research.
- Unstructured text/image/PDF/email handling: Generative AI / LLM.
- High-risk judgment: keep human or use AI-assisted mode only.

## Required controls

- Human-in-the-loop for high-risk decisions.
- Fallback mechanism for model failure or outage.
- Legal clearance when required.
- Technical platform assessment for SMART vs Compass.
- Re-test after model changes.
- Maintenance plan for knowledge base and prompts.

## Output

Return AI readiness: not AI-suitable / POC-ready / pilot-ready / productization-ready, with blockers.
